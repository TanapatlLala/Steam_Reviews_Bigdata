1. 📁 Raw Data Management

เริ่มต้นจากไฟล์ CSV ขนาดใหญ่ 43GB ซึ่งไม่สามารถโหลดเข้า RAM ปกติได้

2. ⚙️ Orchestration with Airflow

ใช้ Airflow ควบคุม Pipeline โดยเน้นการทำ Chunking เพื่อประมวลผลข้อมูลทีละส่วนอย่างปลอดภัย

3. 💾 Storage Optimization

แปลงข้อมูลเป็น Parquet เพื่อประหยัดพื้นที่ 50% และเพิ่มความเร็วในการอ่านข้อมูลเฉพาะคอลัมน์

4. 🚀 Real-time Analysis

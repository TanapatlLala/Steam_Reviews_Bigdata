นักศึกษาจะต้องเลือกData set โดยดำเนินการตามกระบวนการ pipeline จนถึงการจัดทำ dashboard
องค์ประกอบการประเมิน ได้แก่:
ความครบถ้วนของ data pipeline (ingest → clean → Parquet/Arrow → analyze) 15%
Dashboard และความถูกต้องของการวิเคราะห์
การทดสอบประสิทธิภาพและการเปรียบเทียบขนาด/เวลา (benchmark)
ความถูกต้องของเอกสาร, README, โครงสร้างรีโพสาธารณะ
การนำเสนอผลงานและการตอบคำถามปากเปล่า
โดย data set ที่ฉันเลือกคือ https://www.kaggle.com/datasets/kieranpoc/steam-reviews แปลเป็น prompt ภาษาอังกฤ

ช่วยเขียนโค้ดโหลด data ให้มีCheckpoint เซฟไว้

แรมของฉันมี ram 16 gb หลังจากนี้เวลาปรับแต่งโค้ดช่วยปรับให้ ram ฉันรับไว้ด้วย

ต่อไปทำ airflow ผ่าน docker compose ช่วยทำให้หน่อย

เปลี่ยน port airflow ให้เป็น port 8081

ในหน้า Docker Desktop  port ไม่เปิดแก้ยังไง

ตอนนี้โปรเจคของฉันทำถึงรัน airflow เสร็จ ต่อไปต้องทำ Dashboard และความถูกต้องของการวิเคราะห์ 
ใช้ไหมฉันใช้ วีธีสร้างDashboard วิธีอะไรดี

ฉันต้องการใช่ Streamlit ต้องตรวจสอบความถูกต้อง (Analytical Accuracy) ก่อน วิธีสร้าง Dashboard ใช่ไหม ต้องทำยังไง

แต่ฉันอยากได้ Dashboard พวกที่แบบแสดงค่าที่ looker studio ที่สามารถเลือก drop down ดุข้อมูลตามปี ดูการฟ เกมไหนได้รีวิวดี เกมไหนได้รีวิวแย่

 ถ้างั้นแก้เป็นกราฟ แท่ง 2 แท่ง มาเลยระหว่าว positive กับ negative แล้วแก้เป็นแค่ 10 อันดับพอ

 อยากให้ช่วยปรับเวลาเลือกข้อมูลแต่ละปี แล้วมันจะเรียงลำดับจากมากไปน้อย

 ตอนนี้ฉันได้  Dashboard  ของ 10 อันดับเกมที่ถูกรีวิวมากที่สุดในแต่ละปี มาแล้ว คุณคิดว่ามี Dashboard  อะไรอีกที่น่าสนใจที่จะเอาข้อมูลมาใส่

 อยากให้บอกเปอร์เซนด้วยของกราฟโดนัน

  ภาษาที่ให้คะแนนแง่บวกสูงสุด เอาแค่ top 10 

  เกมที่ครองเวลาผู้เล่นนานที่สุด การฟที่แสดงเวลาเล่นเกมนานที่สุดของแต่ละปี

  ตอนนี้หน้า dashboard อยากเพิ่ม Filters ตรงรายปีที่รวมข้อมูลทุกปี และฉันอยากได้ค่า scroecard เพิ่มด้านบนสุดก่อนกราฟแต่ยังไม่รู้จะใส่ข้อมูลอะไรมีแนะนำไหม

  ฉันสนใจเพิ่มกราฟ Word Cloud ฉันอยากให้ดูง่ายกว่านี้แบบ top 10 คำนิยมอะไรแบบนี้

  ช่วยเขียน สคริปต์ Benchmark (เปรียบเทียบขนาดและความเร็ว) ให้หน่อย
